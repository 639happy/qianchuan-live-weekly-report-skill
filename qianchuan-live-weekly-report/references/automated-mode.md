# 全自动Chrome模式

全自动是“前提准备完成后由Codex执行”，不是绕过登录和权限的一键抓取。

## 安装前应知道

用户需要：

1. 可正常使用的Codex桌面客户端。
2. 已安装并启用的官方Chrome插件。
3. Chrome侧扩展已经按官方引导取得所需浏览器权限。
4. 使用安装扩展的同一个Chrome用户配置。
5. 在该配置中登录电商罗盘和巨量千川。
6. 账号有权查看目标直播间、直播详情和同周期千川数据。
7. 允许目标后台域名访问和任务需要的下载权限。

目标域名：

- `compass.jinritemai.com`
- `qianchuan.jinritemai.com`

## 逐项预检

一次确认一项，并记录通过或失败：

1. Codex桌面客户端和当前任务可正常调用浏览器。
2. Chrome插件已安装、启用并连接到当前任务。
3. 当前是同一个Chrome用户配置。
4. 罗盘已登录，目标账号和周期场次可见。
5. 千川已登录，目标账号和完整周期结果可见。
6. 两个域名已获允许。
7. 固定下载目录、自动下载和多文件下载权限可用。
8. 账号、周期、时区、退款成熟度和场次分组已确认。

输出四类结果：

- 已通过
- 未通过
- 必须由用户完成
- Codex可以重试

不得未经用户同意切换为文件模式。

## 小样本验证

先选择2—3场，验证：

- 账号没有混入。
- 场次详情入口和`live_room_id`可稳定取得。
- 自然流量观看人数和核心漏斗字段名称仍然存在。
- 罗盘导出结构可以按字段名识别。
- 千川结果来自同账号、同完整周期。
- 下载文件可以被Codex读取。

小样本通过后再运行完整周。小样本失败时，输出字段差异、权限缺口和恢复动作，不直接扩大抓取。

## 正式取数

1. 选择目标账号和周期。
2. 下载并归档罗盘官方直播明细。
3. 逐场打开详情并补充网页字段。
4. 取得千川同账号、同完整周期经营数据。
5. 对照配置重新校验账号和周期。
6. 只在本地输出目录保存原始下载和运行记录，不写入Skill安装目录或公开仓库。

## 必须停止并交给用户

出现以下情况时停止自动操作：

- 验证码、二维码、滑块或账号风控。
- 登录失效或要求重新授权。
- 当前账号无目标数据权限。
- 浏览器要求扩大网站访问权限。
- 页面字段发生实质变化。

遇到验证码时立即停止，等待用户本人完成后再继续。

不要读取、导出或要求用户提供密码、Cookie、token、验证码、浏览器会话存储。

用户完成必要动作后，从最后一个已确认阶段继续，不重新抓取已完成日期和场次。
