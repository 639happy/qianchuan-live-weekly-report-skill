## 1. 真相源边界

- 电商罗盘负责直播总流量、观看、停留、商品漏斗、直播成交、退款和场次行为。
- 巨量千川负责付费消耗、计划、素材和付费归因成交。
- 不把罗盘项目计算值写成千川原生归因值。
- `付费流量观看人数`是`直播间观看人数－自然流量观看人数`的项目计算值。
- 无法明确识别的流量写作“未归因流量”，不能用总流量减千川归因流量后直接命名为免费流量。
- `自然流撬动系数`用于经营观察，不代表已经证明付费流量导致免费流量。

## 3. 扩展19列

按以下顺序追加在原始字段右侧：

| 字段 | 来源或公式 | 空值与边界 |
|---|---|---|
| `live_room_id` | 罗盘场次列表或详情入口 | 按文本保存 |
| 直播详情页URL | 当前场次详情入口 | 去除无关追踪参数 |
| 自然流量观看人数 | 单场详情页核心数据 | 未匹配时留空 |
| 付费流量观看人数 | 直播间观看人数－自然流量观看人数 | 小于0判定异常 |
| 自然流量观看占比 | 自然观看÷总观看人数 | 总观看为0时留空 |
| 付费流量观看占比 | 项目计算付费观看÷总观看人数 | 总观看为0时留空 |
| 自然流撬动系数 | 自然观看÷项目计算付费观看 | 付费观看为0时留空 |
| 自然流撬动系数状态 | 可计算、无付费基数、自然观看缺失或网页未匹配 | 质量状态 |
| 千次观看用户支付金额（罗盘口径） | 直播间用户支付金额÷直播间观看次数×1000 | 观看次数为0时留空 |
| 千次观看支付数据来源 | 罗盘网页公式复核、原始数据公式补算或待核验 | 来源状态 |
| 曝光→观看率 | 直播间观看人数÷直播间曝光人数 | 人数口径 |
| 观看→商品曝光率 | 商品曝光人数÷直播间观看人数 | 人数口径 |
| 商品曝光→点击率 | 商品点击人数÷商品曝光人数 | 人数口径 |
| 商品点击→成交率 | 成交人数÷商品点击人数 | 人数口径 |
| 曝光→成交率 | 成交人数÷直播间曝光人数 | 人数口径 |
| 场次分组 | 用户确认的开始时间与时长规则 | 不套用示例账号规则 |
| 工作日/周末 | 按配置时区判断 | 仅作标签 |
| 是否纳入同类场次趋势 | 按用户确认的场次分组规则 | 是、否（仅描述）或否 |
| 网页数据匹配状态 | 场次与详情页匹配结果 | 已匹配、未匹配或详情页暂无数据 |

`千次观看用户支付金额（罗盘口径）`不等于千次广告曝光成交金额，也不与广告GPM混用。

## 4. 汇总规则

- 一场直播一行。
- 分组漏斗率使用分子合计÷分母合计。
- 分组自然流撬动系数使用自然观看合计÷项目计算付费观看合计。
- 不直接平均各场比率。
- 人均观看时长按观看人数加权。
- 周报经营金额使用直播间成交金额；用户支付金额保留为独立口径。
- 退款比例的分子、分母和成熟度必须写清楚。
- 乘方当前页面的`综合营销ROI`和旧页面的`综合ROI`统一映射为项目字段`comprehensive_roi`，但必须保留页面原始标签。
- 综合ROI使用千川同账号、同完整周期、同账号行的净成交金额÷综合成本复核；不得直接使用包含多个抖音号的顶部汇总。
- 页面显示ROI与公式复核值的四舍五入差异超过0.02时停止合并并标记口径异常。
- 罗盘投放消耗不自动替代千川综合成本。

## 5. 数据成熟度与缺失值

- D0、D1、D7、D14快照分别保存，不覆盖历史。
- 跨周比较只比较同退款成熟度。
- 缺失数据保留空值并写明原因，不补0。
- 分母为0时比率留空。
- 页面字段变化或详情未匹配时，只输出假设和待核验项。
- 账号、日期窗口或来源口径不一致时停止合并。
